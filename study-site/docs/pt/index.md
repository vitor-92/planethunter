# Caçadores de Planetas

Um curso para quem nunca estudou astronomia e quer entender, de verdade, como se procuram planetas fora do Sistema Solar, e como funciona o **PlanetHunter**, uma ferramenta que faz essa busca nos dados públicos do telescópio espacial TESS.

!!! abstract "O que você vai conseguir fazer"
    - Explicar como uma pequena queda no brilho de uma estrela revela um planeta.
    - Distinguir um planeta de uma estrela dupla, de uma vizinha contaminando o sinal e de um defeito do telescópio.
    - Ler um dossiê de candidato e decidir, com critério, se ele merece atenção.
    - Rodar análises em Python com dados reais do TESS.
    - Entender cada decisão de projeto do PlanetHunter e medir o efeito de mudá-la.

## Por onde começar

1. Leia [Como estudar](how-to-study.md) (5 minutos).
2. Abra a aula [B1. Céu, estrelas e planetas](basic/b1-sky-stars-planets.md).
3. Brinque com o [simulador](lab/transit-simulator.md) quando chegar à aula B2.

!!! info "Sobre o conteúdo"
    O curso segue o plano de estudos do projeto PlanetHunter e usa exemplos reais da primeira semana de buscas (setores 69 e 107 do TESS, outubro de 2026). Quando um número aparece, ele foi medido, não inventado.
