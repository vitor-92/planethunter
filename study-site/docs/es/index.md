# Cazadores de Planetas

Un curso para quien nunca estudió astronomía y quiere entender, de verdad, cómo se buscan planetas fuera del Sistema Solar, y cómo funciona **PlanetHunter**, una herramienta que hace esa búsqueda en los datos públicos del telescopio espacial TESS.

!!! abstract "Lo que vas a poder hacer"
    - Explicar cómo una pequeña caída en el brillo de una estrella revela un planeta.
    - Distinguir un planeta de una estrella doble, de una vecina que contamina la señal y de un defecto del telescopio.
    - Leer un dossier de candidato y decidir, con criterio, si merece atención.
    - Ejecutar análisis en Python con datos reales de TESS.
    - Entender cada decisión de diseño de PlanetHunter y medir el efecto de cambiarla.

!!! info "Sobre el contenido"
    El curso sigue el plan de estudios del proyecto PlanetHunter y usa ejemplos reales de la primera semana de búsquedas (sectores 69 y 107 de TESS, octubre de 2026). Cuando aparece un número, fue medido, no inventado.
